## About me

I'm a **Systems Analysis and Development** student building a career in cybersecurity.

My current focus is understanding how software, networks and web applications fail, so I can learn how to build systems that are harder to break. I am especially interested in offensive security, application security, security tooling, bug bounty workflows and automation.

I also have hands-on experience with **IT support / help desk**, troubleshooting, networks, Windows, Linux and technical service, which helps me approach security with a practical, system-level mindset.
