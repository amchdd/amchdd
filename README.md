Estudo desenvolvimento web e segurança de aplicações. Aprendo melhor quando consigo transformar uma ideia em algo que funciona, testar as decisões que tomei e documentar o que ainda precisa melhorar.

Já atuei com suporte de TI e help desk. Essa experiência me ensinou a ouvir o problema, investigar com calma e explicar soluções de forma simples. Hoje aplico esse cuidado tanto no desenvolvimento quanto nos meus estudos de segurança.

Tenho interesse em AppSec, segurança web e automação. Também estudo Python para criar scripts e experimentar ideias, enquanto sigo construindo projetos com TypeScript e Go.

### Projetos

**[Doces da Mari](https://docesdamari.com.br/)** · [repositório privado](https://github.com/amchdd/Doces-Mari)

Catálogo e sistema de encomendas com painel para administrar produtos, categorias e pedidos. Trabalhei na interface em React e TypeScript e na API em Node.js e Express, com PostgreSQL para os dados, Supabase Storage para imagens e Redis para controles temporários. O projeto inclui autenticação administrativa e testes de segurança.

**[Subdomainabber](https://github.com/amchdd/subdomainabber)**

Ferramenta em Go para investigar possíveis casos de takeover de subdomínio em escopos autorizados. Ela cruza observações de DNS, HTTP e TLS, registra evidências e guarda o histórico em SQLite. A saída diferencia sinais que pedem investigação de casos com prova de controle, para evitar conclusões além da evidência.
